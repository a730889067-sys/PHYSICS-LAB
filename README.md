# مختبر الفيزياء — PHYSICS-LAB

تطبيق أندرويد تعليمي باللغة العربية، بواجهة من اليمين إلى اليسار، ومحتوى يعمل محلياً دون اتصال بالإنترنت.

## الموجود في النسخة التأسيسية
- واجهة عربية متجاوبة مع الهاتف.
- دروس تمهيدية في الحركة والسرعة، والقوة وقوانين نيوتن، والجاذبية، والطاقة، والكهرباء.
- محاكيات تفاعلية مبسطة للحركة والقوة، والسقوط الحر، والكهرباء، والطاقة.
- اختبار قصير مع حفظ التقدم على الجهاز.
- تطبيق Android يستخدم WebView مع ملفات محلية مضمّنة داخل APK؛ لا يحتاج اتصالاً بالشبكة لتشغيل الدروس والتجارب.

## بناء APK
كل تغيير على الفرع main يشغّل GitHub Actions تلقائياً. بعد اكتمال البناء:
1. افتح تبويب Actions في المستودع.
2. افتح أحدث عملية Build PHYSICS-LAB Android APK.
3. من قسم Artifacts نزّل PHYSICS-LAB-debug-apk.

هذا ملف APK تجريبي (Debug) وليس نسخة إصدار موقّعة للنشر. يجب اختبار التطبيق على أجهزة فعلية قبل توزيعه.

## متطلبات البناء
- JDK 17
- Gradle 8.9
- Android SDK 35
- Android Gradle Plugin 8.7.3
